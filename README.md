# Warm Story

Portfolio bilingual berbasis Astro dengan:

- public site `id/en`
- admin panel internal
- Better Auth
- MySQL
- Drizzle

## Command

Semua command dijalankan dari root project:

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run db:push`
- `npm run db:seed-content`
- `npm run db:seed-projects`
- `npm run auth:seed-admin`
